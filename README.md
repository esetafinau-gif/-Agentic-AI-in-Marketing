
# Ad Optimization Agent in Marketing

## Overview
This project produces a simple Ad Optimization Agent that reviews daily advertising results and proposes changes to the budgets of the Search, Social, and Display channels. The agent reviews results from each channel separately and selects the buckets with higher conversions and relatively low or high budget requirements. The overall objective is to scale conversions with minimal and interpretable budget adjustments.
